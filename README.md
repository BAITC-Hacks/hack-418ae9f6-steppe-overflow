# Steppe Overflow — Agentic AI прогноз выработки ВЭС

> ⚠️ Черновик: проект в разработке. README описывает только то, что уже реализовано.

Система прогнозирования почасовой выработки ветроэлектростанции (2 турбины, Алматинская область) на горизонте 24–48 часов.

## Что реализовано на текущий момент

- Загрузка SCADA-данных турбин (10-минутные записи), перевод меток из UTC+6 в UTC.
- Контроль качества: пометка простоев и ограничений мощности.
- Почасовая агрегация по турбинам и по ВЭС в целом.
- Командная строка `windagent data` — сводка по данным и экспорт почасового датасета.

## Установка и запуск

Нужен [uv](https://docs.astral.sh/uv/) — он сам установит Python 3.12 и зафиксированные версии библиотек.

```bash
uv sync
uv run windagent data
uv run pytest
```

Без `uv`:

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install -e .
windagent data
```

## Данные

`Dataset/` — исторические данные двух турбин с 11.03.2023 по 31.01.2026: время (UTC+6), средняя скорость ветра (м/с), нормализованная активная мощность, температура (°C).
