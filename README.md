# Steppe Overflow — Agentic AI прогноз выработки ВЭС

Система прогнозирования почасовой выработки ветроэлектростанции (2 турбины, Алматинская область) на горизонте 24–48 часов.

## Что реализовано на текущий момент

- Загрузка SCADA-данных турбин (10-минутные записи), перевод меток из UTC+6 в UTC.
- Контроль качества: пометка простоев и ограничений мощности.
- Почасовая агрегация по турбинам и по ВЭС в целом.
- Командная строка `windagent data` — сводка по данным и экспорт почасового датасета.
- Архив прогнозов погоды из Open-Meteo, сохранённый в `cache/weather/` (работает без интернета):
  - отдельные прогоны ECMWF IFS (00/06/12/18 UTC) с 15.03.2024 с известным временем старта;
  - прогнозы ECMWF IFS 0.25°, GFS и ICON, выпущенные за 1–3 суток до нужного часа (Previous Runs API);
  - реанализ ERA5 — только для анализа, в прогнозе не используется.
- `DataStore(as_of)` — доступ к данным «как в прошлом»: отдаёт только прогоны погоды, опубликованные до момента прогноза, и только завершившиеся часы SCADA. Попытка взять более поздние данные вызывает `LeakageError`.

## Установка и запуск

Нужен [uv](https://docs.astral.sh/uv/) — он сам установит Python 3.12 и зафиксированные версии библиотек.

```bash
uv sync
uv run windagent data              # сводка по данным турбин
uv run windagent weather status    # что есть в кэше погоды
uv run pytest                      # тесты (без интернета)
```

Кэш погоды уже лежит в репозитории. Обновить его из Open-Meteo (нужен интернет, ~15 минут):

```bash
uv run windagent weather download --what single,previous,era5
```

Без `uv`:

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install -e .
windagent data
```

## Данные

### Данные турбин

`Dataset/` — исторические данные двух турбин с 11.03.2023 по 31.01.2026: время (UTC+6), средняя скорость ветра (м/с), нормализованная активная мощность, температура (°C).

### Прогнозы погоды — [Open-Meteo](https://open-meteo.com/)

| API | Что берём | Зачем |
|---|---|---|
| Single Runs | прогоны `ecmwf_ifs` с точным временем старта | основной источник прогноза ветра |
| Previous Runs | `ecmwf_ifs025`, `gfs_seamless`, `icon_seamless`: прогнозы, выпущенные 1–3 суток назад | дополнительные модели |
| Archive (ERA5) | реанализ | проверка часового пояса данных, анализ |

Прогон считается доступным через фиксированную задержку после старта: ECMWF — 7 ч, GFS — 5 ч, ICON — 4 ч (`config/settings.yaml`).
